## Структура проєкту

```text
lab-oop-numerical-integration/
├── integrators.py   # Модуль з ієрархією класів інтеграторів (BaseIntegrator та нащадки)
├── main.py          # Виконуваний файл із підінтегральною функцією та запуском обчислень
├── .gitignore       # Файл виключень Git 
└── README.md        # Документація проєкту та звіт із результатами
```

### Архітектура класів (`integrators.py`)
* **BaseIntegrator** — базовий клас-шаблон, містить перевірку меж (`@staticmethod`), читання словника параметрів (`@classmethod`) та алгоритм обчислення за правилом Рунге (adaptive_integrate)
* **RectangleIntegrator** — реалізація формули середніх прямокутників 
* **TrapezoidIntegrator** — реалізація формули трапецій 
* **SimpsonIntegrator** — реалізація формули Сімпсона

## Задача

Обчислити визначений інтеграл:

* **e^(sin(x))** в межах 0, 1

із заданими точностями 0.0002 та 0.00002 трьома чисельними методами, визначивши для кожного методу мінімальну парну кількість розбиттів
